Apple·Google의 로그인 창에서 이루어지는 정보 처리는 각 회사의 개인정보 정책을 따릅니다.

로그인하면 그 기기의 크레딧 잔액이 계정으로 옮겨지고, 그 뒤의 구매·지급·사용 내역이 계정에 쌓이며, 같은 계정으로 로그인한 기기는 같은 잔액을 봅니다. 「이 기기에서 로그아웃」을 하면 그 기기만 계정에서 풀리고 잔액은 계정에 남습니다. 이 기능이 들어 있는 버전은 설정 화면이나 결제 화면을 열 때 기능이 켜져 있는지와 이 기기가 계정에 묶여 있는지를 서버에 확인하며, 이 확인에는 설치 토큰만 전송되고 계정 정보는 전송되지 않습니다. 계정을 삭제하는 방법과 삭제 뒤에 남는 정보는 §03과 §05에 적었습니다.

호칭과 이름. 한국어 화면에서 앱은 이용자를 기본 호칭 「회원님」으로 부릅니다. 온보딩 또는 앱 [설정 - 호칭·캠퍼스]에서 다른 호칭(선생님)을 고르거나 이름을 직접 입력할 수 있습니다. 영어 화면에서는 호칭을 쓰지 않으며, 같은 자리에서 이름을 선택으로 입력할 수 있고 입력하지 않으면 이름 없이 진행됩니다. 호칭·이름과 캠퍼스 이름은 기기에만 저장됩니다. 다만 AI 튜터에게 질문할 때에는 유니가 같은 호칭으로 부르도록 호칭(이름을 입력한 경우 「님」을 붙인 꼴로, 12자 이내)이, 영어 화면에서는 입력한 이름이 있을 때에만 그 이름(서버가 받는 길이는 24자 이내)이 질문과 함께 전달되며, 서버에는 저장되지 않습니다. 이름이 전달되는 것을 원하지 않으면 이름 대신 「회원님」 같은 호칭을 고르고, 영어 화면에서는 이름 칸을 비워 두시기 바랍니다.

AI 튜터와 AI 채점. 이용자가 튜터에게 질문을 보내면, 질문 내용과 현재 레슨의 제목·요약·용어·보고 있는 화면의 글 같은 맥락 정보, 그리고 호칭(영어 화면에서는 입력한 이름)이 운영자의 중계 서버(Cloudflare Workers)를 거쳐 Anthropic, PBC의 Claude 모델에 전달되고, 생성된 답변이 실시간으로 돌아옵니다. 의뢰에서 「AI 라이브 채점」을 고르면 이용자가 쓴 제출문과 채점 기준이 같은 경로로 전달됩니다. 두 요청에는 답변과 채점의 언어를 정하기 위해 읽고 있는 레슨의 언어(한국어 또는 영어)를 나타내는 값이 함께 실립니다. 중계 서버는 설치 토큰 검증, 요청 빈도 제한, 무료 체험 횟수, 크레딧 잔액, 비용 상한 확인만 수행하며 질문·제출문·답변 본문을 저장하지 않습니다. 운영자는 이용자의 질문이나 답변을 AI 모델 학습에 사용하지 않으며, Anthropic에 전달된 내용의 처리는 Anthropic의 상업용 API 약관과 개인정보 정책을 따릅니다. 대화 기록은 이용자의 기기에만 남고, 앱 [설정 - 튜터·BYOK - 튜터 「유니」]에서 대화별로 삭제할 수 있습니다. 질문에 이름·전화번호·주민등록번호·건강 상태 등 개인정보를 입력하지 마시기 바랍니다. 앱과 서버는 주민등록번호·카드 번호·전화번호·이메일 주소·비밀번호처럼 보이는 내용이 있으면 질문을 AI에 보내지 않고 안내문을 보여 주지만, 이 필터는 완전하지 않습니다.

직접 입력한 API 키(BYOK). 고급 단계에서 이용자가 자신의 Anthropic API 키를 등록하면 앱이 Anthropic에 직접 요청을 보냅니다. 키와 요청 내용(질문·레슨 맥락·호칭 또는 이름)은 운영자 서버를 거치지 않으며, 키는 기기의 보안 저장소에만 보관됩니다. 이때 데이터 처리는 Anthropic의 약관과 개인정보 정책을 따릅니다.

설치 정보. AI 튜터·AI 채점을 처음 이용하거나 구매를 확인할 때, 또는 선택 로그인 기능이 들어 있는 버전에서 설정 화면이나 결제 화면을 처음 열 때 중계 서버가 무작위 설치 ID와 서명 토큰을 발급하고, 앱은 이를 iOS Keychain 또는 Android 암호화 저장소에 보관합니다. 발급 요청에는 플랫폼(iOS / Android)과 앱 버전, 그리고 앱이 기기에서 만든 무작위 설치 키만 담기며, 서버는 여기에 발급 시각과 설치 키의 해시값을 함께 기록합니다(설치 키는 같은 설치임을 다시 확인하는 데만 쓰이고, 접속 국가와 IP 주소는 설치 정보에 기록하지 않습니다). 설치 정보는 무료 체험 횟수 계산, 남용 방지, 크레딧 잔액 관리에만 사용되며 이름·이메일·광고 식별자·기기 고유번호와 연결되지 않습니다(선택 로그인을 이용한 경우에만 계정 식별값의 해시와 연결됩니다). iOS에서는 앱을 지워도 설치 ID가 기기의 Keychain에 남아 같은 기기에 다시 설치하면 이어지고, Android에서는 앱을 삭제하거나 앱 데이터를 지우면 함께 사라집니다. 로그인하지 않은 경우, Android에서 앱을 삭제하거나 어느 플랫폼에서든 기기를 바꾸거나 초기화하면 남은 AI 크레딧을 다시 불러올 수 없습니다. 선택 로그인으로 잔액을 계정에 묶어 둔 경우에는 같은 로그인 제공자(Apple 또는 Google)로 다시 로그인해 이어 받을 수 있습니다.

마이크. 현재 버전은 마이크와 음성 인식 권한을 사용하지 않습니다.

콘텐츠 팩 다운로드. 레슨 이미지·음성 등 콘텐츠 팩과 그 목록은 운영자의 Cloudflare 서버(Workers 정적 자산)에서 내려받습니다. 이 요청에는 IP 주소 같은 통상적인 접속 정보만 포함되고 학습 기록이나 설치 ID는 포함되지 않습니다.

외부 링크와 공유. 레슨의 「지금 실제 앱 열기」, 자료실의 출처 링크는 이용자가 누를 때 기기의 브라우저나 해당 앱으로 이동하며, 이동한 뒤의 정보 처리는 그 서비스의 정책을 따릅니다. 수료증·환각 탐정 결과의 공유와 백업 파일 내보내기는 이용자가 직접 고른 앱으로만 전달됩니다.

광고. 무료 이용 시 Google AdMob 광고(배너·전면·앱 오픈·보상형·네이티브)가 표시되며, AdMob SDK가 광고 식별자를 수집해 Google과 공유합니다. iOS에서는 광고 식별자 사용 동의를 묻는 앱 추적 투명성(App Tracking Transparency) 시스템 창이 표시되며, 거부해도 일반 광고는 그대로 표시됩니다. 레슨·의뢰·퀴즈·튜터 진행 중에는 광고를 표시하지 않으며, Pro 구독 또는 평생권을 구매하면 광고가 표시되지 않습니다. Pro 상태로 앱을 시작하면 광고 SDK를 켜지 않고, 아래의 광고 개인정보 동의 확인과 추적 동의도 하지 않습니다.

광고 개인정보 동의. 무료 이용자가 앱을 실행하면 광고를 준비하기에 앞서 Google의 동의 관리 도구(User Messaging Platform)가 이 기기가 광고 개인정보 동의가 필요한 지역에 있는지와 이전에 고른 동의가 아직 유효한지를 Google에 확인합니다. 이 확인은 앱을 실행할 때마다 이루어지고, 앱의 광고 앱 ID가 쓰이며, 그 밖에 이 도구가 Google에 보내는 정보와 그 처리는 Google의 정책을 따릅니다. 유럽경제지역(EEA)·영국·스위스처럼 관련 규정이 동의를 요구하는 지역에서는, 운영자가 그 지역용 동의 창을 게시해 둔 경우 Google이 제공하는 동의 창이 표시되고, 고른 내용은 Google에 전달되며 기기에도 저장됩니다. 동의하지 않음을 골라도 앱은 그대로 이용할 수 있고 광고는 표시될 수 있으며, 이때 어떤 광고가 표시되는지는 고른 내용에 따라 Google이 정합니다. 미국 일부 주처럼 관련 규정이 광고 개인정보에 관한 선택권을 요구하는 지역에서도, 운영자가 그 지역용 안내를 게시해 둔 경우 Google이 제공하는 안내 창이 표시될 수 있습니다. 앱 [설정 - 정보 - 광고 개인정보 설정] 메뉴는 Google의 동의 관리 도구가 다시 고를 수 있어야 하는 지역이라고 알려 준 경우에 무료 이용자에게 표시되며, 표시되는 경우 이 메뉴에서 언제든 다시 고를 수 있습니다. 대한민국처럼 동의 창이 필요하지 않은 지역에서는 창이 표시되지 않고 이 메뉴도 보이지 않습니다. 순서는 광고 개인정보 동의 확인(필요한 지역에서는 동의 창) → iOS의 앱 추적 투명성 창 → 광고 SDK 시작입니다. 동의 상태를 확인하지 못한 실행에서는 기기의 시간대와 지역 설정을 기기 안에서만 참고해, 동의가 필요한 지역일 수 있으면 그 실행 동안 광고 SDK를 켜지 않고 추적 창도 띄우지 않습니다.

이용 연령. 서비스는 만 13세 미만 어린이를 대상으로 하지 않습니다(스토어에 표시되는 연령 등급은 각 스토어의 산정을 따릅니다). 앱은 이용자의 나이나 생년월일을 묻거나 저장하지 않습니다. 만 14세 미만 이용자는 법정대리인의 동의를 받은 뒤 이용해야 하며, 운영자는 만 14세 미만 아동의 개인정보가 동의 없이 수집된 사실을 알게 되면 지체 없이 삭제합니다.

02이용 목적

  • 학습 기록·설정 - 진도 저장, 복습 일정, 통계와 보상 표시, 수료증 발급, 다음 실행에서 같은 설정 유지
  • 호칭·이름 - 앱 화면과 AI 튜터 답변에서 이용자를 부르는 말로 사용
  • AI 튜터 질문·레슨 맥락, AI 채점 제출문 - 질문에 대한 AI 답변 생성, 의뢰 제출문의 AI 채점
  • 설치 정보·사용량 기록·접속 IP 주소 - 무료 체험 횟수 적용, 자동화 호출·남용 방지, 서비스 전체 비용 상한 관리
  • 크레딧 원장·구매 정보 - 구매한 크레딧 적립과 차감, Pro 구매 확인과 매월 AI 크레딧 지급, 중복 적립 방지, Pro 혜택 제공과 구매 복원
  • 계정 정보(선택 로그인) - 구매한 AI 크레딧 잔액을 계정에 묶어 재설치·기기 변경 뒤에도 이어 받게 함, 계정 삭제 요청 때의 본인 확인
  • 직접 입력한 API 키 - 이용자 본인 계정으로 Anthropic 직접 호출 (기기 내 보관)
  • 문의·신고 이메일 - 신고된 답변 확인과 회신, 문의 응대
  • 광고 식별자 - 모바일 광고 노출(맞춤형 광고 포함), 빈도 제한 및 부정 클릭 방지 (Pro·평생권 구매 시 광고 미표시)
  • 광고 개인정보 동의 상태 - 관련 규정이 요구하는 지역에서 광고 개인정보 동의를 받고, 고른 내용에 맞게 광고를 요청
  • 앱 사용 진단 - 안정성 개선 및 오류 수정

운영자는 위 정보를 이용자 개인을 식별하거나 프로파일링하는 목적으로 사용하지 않으며, 별도의 분석(애널리틱스) SDK를 사용하지 않습니다. 이용자의 질문·답변·학습 기록은 AI 모델 학습이나 광고 목적에 사용되지 않습니다.

03보유 및 이용 기간

  • 기기 내부 저장 정보(학습 기록, 설정, 호칭, 튜터 대화 기록, 콘텐츠 팩)는 이용자가 앱에서 삭제하거나 앱을 제거할 때까지 기기에 보관되며, 운영자가 보유하는 사본은 없습니다. 이용자가 직접 만든 백업 파일은 이용자가 관리합니다.
  • 기기 보안 저장소의 설치 ID·토큰·설치 키와 직접 입력한 API 키는 Android에서는 앱 제거와 함께 삭제됩니다. iOS에서는 앱을 제거해도 기기의 Keychain에 남을 수 있으므로, API 키는 앱 제거 전에 앱 [설정 - 튜터·BYOK - 내 키 넣기]에서 지우시기 바랍니다.
  • AI 튜터 질문·AI 채점 제출문·답변 본문은 답변 생성이 끝나면 중계 서버에 남지 않습니다. Anthropic은 자사 정책에 따라 남용 탐지 등의 목적으로 제한된 기간 입력을 보관할 수 있습니다.
  • 무료 체험 사용 횟수(설치 ID별)는 설치 정보와 같이 서비스를 제공하는 동안 보관하며, 삭제 요청을 받거나 서비스를 종료하면 삭제합니다. 요청 빈도 제한 카운터(접속 IP 주소를 변환한 값·설치 ID 기준)는 최대 2시간 뒤 자동 삭제됩니다. 호출별 기록(설치 ID 앞 8자리, 모델명, 토큰 수, 비용, 응답 시간, 상태 코드)과 선택 로그인·계정 삭제 요청의 처리 기록(요청 종류, 상태 코드, 실패 사유), 그리고 Cloudflare가 서버 요청마다 자동으로 남기는 접속 기록(§01 표 「접속 IP 주소」)은 Cloudflare Workers 로그의 보관 기간(현재 Cloudflare 요금제에 따라 3일 또는 7일) 동안만 남으며, 일별 합계는 개별 설치와 무관한 형태로 비용 관리를 위해 보관합니다.
  • 설치 정보(설치 ID, 플랫폼, 앱 버전, 발급 시각, 마지막 발급일, 설치 키의 해시값)는 서비스를 제공하는 동안 보관하며, 삭제 요청을 받거나 서비스를 종료하면 삭제합니다.

06Security Measures

  • The service is designed around not collecting personally identifiable information in the first place; the server distinguishes users by a random install ID, and even if you use optional sign-in the account identifier is stored only as a hashed value.
  • For optional sign-in, the server verifies the provider's signature on the sign-in token, its intended audience, its expiry, and a confirmation value (nonce, valid for 10 minutes) issued by the server. Tokens, authorization codes, email addresses, and names are not stored or logged.
  • AI tutor question and answer text is not written to the relay's logs or databases. The call records we write contain only the first 8 characters of the install ID, usage figures, and the request type, time, status code, failure reason, and latency, and no IP address. Separately, the connection records that Cloudflare keeps automatically for each request to the server (the request address, time, and similar details, which may include the IP address and country of the connection) may remain for the retention period of Cloudflare Workers logs (section 03).
  • The install token, install key, and your API key are kept in the iOS Keychain / Android encrypted storage; the token is signed (HMAC-SHA256) to prevent forgery and reissued every 30 days. The server keeps only a hash of the install key.
  • Credit purchases and Pro purchases are verified server-side against Apple-signed transaction data or the Google Play Developer API, with a unique constraint on transaction identifiers to block duplicate grants.
  • Content packs are installed only after their digital signature and hashes are checked.
  • Per-install and per-IP rate limits and a service-wide cost cap guard against automated calls and abuse.
  • All external communication is encrypted with HTTPS, and the app does not allow unencrypted connections.
  • We rely on the security standards of our processors (Cloudflare, Anthropic, Google, and others).
